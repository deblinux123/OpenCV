# 📘 یادگیری OpenCV (بینایی ماشین با پایتون)

این مخزن برای **یادگیری گام‌به‌گام OpenCV** طراحی شده است و مناسب افراد مبتدی تا متوسط در حوزه‌ی **بینایی ماشین (Computer Vision)** می‌باشد. در این پروژه، مفاهیم پایه تا کاربردی OpenCV با مثال‌های عملی و کد پایتون آموزش داده می‌شوند.

---

## 🎯 اهداف پروژه

* آشنایی با مفاهیم پایه‌ی بینایی ماشین
* یادگیری کار با کتابخانه OpenCV
* پردازش تصویر و ویدئو
* پیاده‌سازی پروژه‌های ساده و کاربردی
* آماده‌سازی برای پروژه‌های پیشرفته‌تر (AI / Deep Learning)

## 📚 سرفصل‌های آموزشی

### 🔹 1. مفاهیم پایه

* خواندن و نمایش تصویر
* فضای رنگی (BGR, RGB, Gray)
* ذخیره تصویر

### 🔹 2. پردازش تصویر

* تغییر اندازه و برش تصویر
* فیلترها (Blur, Gaussian, Median)
* تشخیص لبه (Canny)
* آستانه‌گذاری (Thresholding)

### 🔹 3. پردازش ویدئو

* کار با وب‌کم
* خواندن و ذخیره ویدئو
* پردازش فریم به فریم

### 🔹 4. تشخیص و استخراج ویژگی

* تشخیص چهره (Haar Cascade)
* کانتور و اشکال
* Bounding Box

### 🔹 5. پروژه‌های عملی

* تشخیص حرکت
* ردیابی اشیاء
* شمارش اشیاء ساده
